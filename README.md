# Пульт объекта

Кабинет заказчика для ремонтных и строительных компаний.

Заказчик видит этап, фото с объекта и деньги. Прораб кидает фото с телефона.

## Тарифы (старт)

- Старт — 2 900 ₽/мес (до 10 объектов)
- Про — 6 900 ₽/мес (до 30 объектов)
- Внедрение — 8 900 ₽ разово
- Пилот 14 дней бесплатно

## Быстрый старт

```bash
npm install
cp .env.example .env.local
# заполни NEXT_PUBLIC_SUPABASE_URL и NEXT_PUBLIC_SUPABASE_ANON_KEY
```

В Supabase SQL Editor выполни `supabase/schema.sql`.

Создай Storage bucket `photos` (private).

```bash
npm run dev
```

## Роли

- **owner** — владелец компании (админка)
- **foreman** — прораб (загрузка фото)
- **customer** — заказчик (просмотр объекта по ссылке)

## Структура

- `/` — лендинг
- `/register` — подключение компании
- `/login` — вход
- `/admin` — панель компании (объекты)
- `/client` — кабинет заказчика

## Деплой

```bash
npm run build
npm start
```
